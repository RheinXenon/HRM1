# 域配置管理使用指南

## 📋 功能概述

域配置管理页面允许您创建和管理自定义的面试领域配置，支持AI智能生成和手动编辑两种方式。

## 🚀 快速开始

### 方式一：AI智能生成（推荐）

1. **输入业务描述**
   - 在"公司/业务描述"文本框中输入公司和业务信息
   - 至少输入20字，描述越详细生成效果越好
   - 例如："一家专注于供应链管理的SaaS公司，主要服务制造业客户..."

2. **点击"AI生成配置"**
   - 等待AI生成完整的域配置（通常需要10-30秒）
   - 生成完成后会自动填充到下方的编辑表单

3. **编辑和调整**
   - 在四个Tab中检查和修改AI生成的内容
   - 可以添加、删除或修改任何配置项

4. **保存配置**
   - 点击"💾 保存配置"按钮
   - 配置将保存到 `domains/{domain_id}/` 目录

### 方式二：使用模板

1. 点击"或使用模板"下拉菜单
2. 选择预设模板（金融科技、教育科技、电商零售等）
3. 点击"📋 应用模板"
4. 在自动填充的基础上进行编辑

### 方式三：从空白开始

1. 点击"🆕 空白配置"按钮
2. 手动填写所有配置项
3. 保存配置

## 📝 配置项说明

### Tab 1: 基本信息

| 字段 | 说明 | 示例 |
|------|------|------|
| 领域名称* | 领域的中文名称 | 金融科技 |
| 领域ID* | 唯一标识符，小写英文+下划线 | fintech |
| 领域描述* | 详细描述该领域的特点 | 金融科技领域涵盖... |
| 适用行业 | 逗号分隔的行业列表 | 银行, 保险, 证券 |
| 典型角色 | 该领域常见的职位 | 风控工程师, 量化分析师 |
| 典型项目 | 常见的项目类型 | 风控系统开发, 交易平台 |
| 典型成就 | 常见的成就描述 | 提升风控准确率30% |

### Tab 2: 技能体系

**技能分类**
- 点击"➕ 添加技能分类"创建新分类
- 每个分类包含：
  - 分类ID（如 backend）
  - 分类名称（如 后端开发）
  - 技能列表（逗号分隔）
  - 描述

**软技能**
- 添加通用软技能
- 格式：id: 名称（如 communication: 沟通能力）

### Tab 3: 问题模板

**三个级别的问题模板**
- 基础级：适用于初级候选人
- 中级：适用于有经验的候选人
- 高级：适用于资深专家

**模板格式**
- 每行一个问题模板
- 使用占位符：`{skill}`, `{concept}`, `{mentioned_concept}`
- 示例：`请介绍一下你对{skill}的理解`

### Tab 4: 评估信号

| 信号类型 | 说明 | 用途 |
|---------|------|------|
| 高级专业术语 | 领域内的高级概念 | 识别候选人是否在装懂 |
| 技术/专业指标 | 量化指标词汇 | 识别实战经验 |
| 具体证据词 | 表示具体案例的词 | 识别真实经验 |
| 模糊词汇 | 不确定的表达 | 识别理解深度不足 |
| 露怯关键词 | 明确不了解的表达 | 识别知识盲点 |
| 空话套话 | 缺乏实质的表达 | 识别空洞回答 |

## 🔧 管理现有域

### 编辑现有域

1. 在"📁 现有域管理"区域点击域名按钮（如 tech, marketing）
2. 配置自动加载到编辑表单
3. 修改任意配置项
4. 点击"💾 保存配置"更新

### 查看JSON配置

点击"👀 预览JSON"按钮可以查看完整的JSON配置结构，方便高级用户直接编辑。

### 重置配置

点击"🔄 重置"按钮清空当前编辑状态，回到初始界面。

## 💡 最佳实践

### AI生成描述技巧

**好的描述示例**：
```
一家金融科技公司，专注于智能风控和信贷评估系统的研发。
主要客户是银行和消费金融机构。核心产品包括反欺诈系统、
信用评分模型和贷后管理平台。技术栈以Python和大数据为主，
团队规模50-100人。
```

**描述要点**：
- 行业领域
- 主要业务/产品
- 目标客户
- 技术特点
- 团队规模（可选）

### 技能分类建议

1. **保持5-8个主要分类**
   - 太少：不够全面
   - 太多：过于分散

2. **每个分类3-10个技能**
   - 包含该分类下最重要的技能
   - 避免过于细化

3. **使用清晰的命名**
   - 分类ID：小写英文（backend, frontend）
   - 分类名称：中文（后端开发，前端开发）

### 问题模板编写

1. **使用占位符**
   ```
   {skill} - 技能名称
   {concept} - 概念名称
   {mentioned_concept} - 候选人提到的概念
   {problem} - 问题场景
   ```

2. **问题要具体**
   - ❌ 不好：你会{skill}吗？
   - ✅ 好：请介绍一下你对{skill}的理解和实践经验

3. **覆盖不同深度**
   - 基础：了解概念
   - 中级：实践应用
   - 高级：原理和架构

### 评估信号词选择

1. **高级术语**
   - 选择该领域特有的专业词汇
   - 候选人容易"不懂装懂"的术语

2. **技术指标**
   - 具体的量化指标
   - 有实战经验才会提到的数据

3. **保持精简**
   - 每类信号10-30个即可
   - 关注高频、高区分度的词汇

## 📁 配置文件结构

生成的域配置保存在 `domains/{domain_id}/` 目录下：

```
domains/
└── fintech/                    # 领域目录
    ├── domain_config.json      # 基本信息
    ├── skills_taxonomy.json    # 技能体系
    ├── question_templates.json # 问题模板
    └── assessment_signals.json # 评估信号
```

## ⚠️ 注意事项

1. **领域ID唯一性**
   - 每个领域ID必须唯一
   - 保存时会覆盖同名域

2. **必填字段**
   - 领域名称、领域ID、描述为必填项
   - 其他字段可选，但建议填写完整

3. **配置验证**
   - 保存前会进行基本验证
   - 确保JSON格式正确

4. **备份重要配置**
   - 编辑现有域前建议备份
   - 可以通过"预览JSON"导出配置

## 🔄 工作流程示例

### 场景：为一家供应链SaaS公司创建域配置

1. **输入描述**
   ```
   一家专注于供应链管理的SaaS公司，主要服务制造业客户，
   提供从采购到交付的全流程数字化解决方案。核心功能包括
   供应商管理、订单追踪、库存优化和物流协调。
   ```

2. **AI生成** → 点击"AI生成配置"

3. **检查和调整**
   - Tab 1: 确认领域ID为 `supply_chain`
   - Tab 2: 检查技能分类，可能需要添加"物流管理"分类
   - Tab 3: 检查问题模板，确保覆盖供应链特有场景
   - Tab 4: 补充行业特定术语（如 JIT、VMI、EDI等）

4. **保存** → 点击"保存配置"

5. **验证** → 在面试控制台中选择新域进行测试

## 🆘 常见问题

**Q: AI生成失败怎么办？**
A: 检查网络连接和API配置，或选择"空白配置"手动创建。

**Q: 可以修改预设的tech/marketing域吗？**
A: 可以，但建议先备份原配置。

**Q: 如何删除一个域？**
A: 直接删除 `domains/{domain_id}/` 目录即可。

**Q: 配置多长时间生效？**
A: 保存后立即生效，刷新面试控制台即可看到新域。
