# 动态配置生成功能说明

## 📋 问题背景

**之前的问题**：
- main_v3.py固定使用`tech_startup`和`senior_backend`配置
- 选择healthcare领域，却面试"创新科技有限公司的高级后端工程师"
- 需要为每个领域手动创建配置文件

**用户反馈**：
- companies和jobs已改名为companies_template和jobs_template（仅作测试模板）
- 不应为每个领域创建固定配置文件
- 应该根据domains动态生成面试内容

---

## ✅ 解决方案

### 核心思路
**从domains文件夹动态生成公司和职位配置**，而不是依赖固定的配置文件。

### 实现方式

#### 1. 新增 `generate_domain_config()` 函数

**位置**: `config/__init__.py`

```python
from config import generate_domain_config

# 根据领域ID动态生成配置
company_config, job_config = generate_domain_config("healthcare")
```

**生成逻辑**：
- 从`domains/{domain_id}/domain_config.json`读取领域信息
- 从`domains/{domain_id}/skills_taxonomy.json`读取技能分类
- 动态生成：
  - 公司名称（来自applicable_industries）
  - 职位名称（来自typical_roles）
  - 必备技能（来自skill_categories前2个类别）
  - 加分技能（来自skill_categories后2个类别）
  - 软技能（来自soft_skills）

#### 2. 修改 `InterviewEngine`

**位置**: `core/interview_engine.py`

**之前**：
```python
def run_interview(self, job_file: str, company_file: str, ...):
    job_config = load_job_config(job_file)
    company_config = load_company_config(company_file)
```

**现在**：
```python
def run_interview(self, candidate_config: Dict, domain_id: str, ...):
    # 自动根据domain_id动态生成配置
    # 向后兼容：仍支持job_file和company_file参数
```

#### 3. 简化 `main_v3.py`

**之前**（248-249行）：
```python
job_file = "senior_backend"  # 固定tech
company_file = "tech_startup"  # 固定tech

result = engine.run_interview(
    job_file=job_file,
    company_file=company_file,
    candidate_config=candidate_config,
    domain_id=domain_id
)
```

**现在**：
```python
result = engine.run_interview(
    candidate_config=candidate_config,
    mode=mode,
    domain_id=domain_id
    # 不传配置文件，自动根据domain_id动态生成
)
```

## 💡 核心优势

### 1. **无需固定配置文件**
- 不需要为每个领域创建company.json和job.json
- 减少配置文件数量和维护成本

### 2. **自动适配领域**
- 根据domain_id自动生成合适的配置
- 技能直接来自domains的skills_taxonomy

### 3. **保持一致性**
- 配置和domains文件夹同步
- 修改domains即可影响面试内容

### 4. **向后兼容**
- 仍支持传入job_file和company_file
- 现有代码无需修改

### 5. **易于扩展**
- 添加新领域只需在domains文件夹创建配置
- 无需修改config代码

## 🔧 技术细节

### 配置生成规则

**公司名称**：
- tech: "创新科技有限公司"（特殊处理）
- 其他："{第一个行业}公司"（如"医院公司"）

**职位名称**：
- 从typical_roles中选择第一个

**必备技能**：
- 从前2个skill_categories中各选3个
- 评分：随机6-8分

**加分技能**：
- 从第3-4个skill_categories中各选2个
- 评分：随机5-7分

**软技能**：
- 从soft_skills中选择前4个
- 评分：随机6-8分
