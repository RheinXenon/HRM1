# 简历生成功能说明

## 功能概述

本次更新为面试系统新增了**智能简历生成**功能，候选人在进入面试时会根据自己的能力和性格特征自动生成一份个性化简历。简历可能存在**夸大**或**过度谦虚**的情况，面试官会根据简历内容针对性地提出2-3个问题。

## 核心特性

### 1. 个性化简历生成

候选人的简历会根据以下因素生成：

- **真实能力等级**：技能的实际水平（1-10分）
- **知识盲区**：
  - **过度自信领域**：简历会夸大该领域的能力（实际能力 < 自我感觉）
  - **过度谦虚领域**：简历会低调描述该领域的能力（实际能力 > 自我感觉）
- **性格特质**（大五人格）：
  - 高外向性：简历风格更积极，多用动词
  - 高尽责性：简历结构规范，细节完整
  - 高开放性：强调创新项目、新技术
  - 高宜人性：强调团队合作
  - 高神经质：描述相对保守

### 2. 基于简历的针对性提问

面试官会分析简历并识别**兴趣点**，包括：
- 简历中提到的高级技术或复杂项目（可能存在夸大）
- 与职位核心要求高度相关的技能描述
- 使用"精通"、"专家级"等词汇的技能
- 项目成就中的量化指标（如"性能提升X倍"）

基于这些兴趣点，面试官会在正式面试开始前提出2-3个针对性问题。

### 3. 简历数据保存

每次面试会生成两份文件：
- **简历文件**：保存在 `data/resumes/` 目录
  - 格式：`resume_{候选人姓名}_{时间戳}.json`
- **面试记录**：保存在 `data/interviews/` 目录
  - 包含简历数据、对话记录、评估结果

## 技术实现

### 新增模块

1. **`core/resume_generator.py`**
   - `ResumeGenerator` 类：负责生成简历
   - `generate_resume()` 方法：基于候选人配置生成简历
   - `format_resume_for_display()` 方法：格式化简历为可读文本

2. **`agents/prompts/resume_prompts.py`**
   - `RESUME_GENERATION_PROMPT`：简历生成提示词
   - `RESUME_BASED_QUESTION_PROMPT`：基于简历的问题生成提示词

3. **`data/resumes/`**
   - 新增文件夹，用于保存候选人简历

### 修改的模块

1. **`agents/interviewer_agent.py`**
   - 新增 `resume_data` 参数到 `__init__`
   - 新增 `generate_resume_based_questions()` 方法

2. **`core/interview_engine.py`**
   - 面试流程中新增简历生成步骤
   - 将简历传递给面试官Agent
   - 生成基于简历的针对性问题
   - 在面试记录中保存简历数据

## 使用示例

### 基本使用

```python
from core.interview_engine import InterviewEngine
from config import load_candidate_config

# 加载候选人配置
candidate_config = load_candidate_config("junior_candidate.json")

# 创建面试引擎
engine = InterviewEngine()

# 运行面试（会自动生成简历）
result = engine.run_interview(
    candidate_config=candidate_config,
    mode="demo",
    domain_id="tech"
)
```

## 面试流程变化

### 更新后的流程

1. 加载配置
2. **生成候选人简历** ⭐ 新增
3. 显示简历内容
4. 初始化Agents（面试官获取简历）
5. 开场白
6. 自我介绍
7. **生成基于简历的针对性问题** ⭐ 新增
8. 生成常规问题
9. 问答循环（简历相关问题优先）
10. 候选人提问
11. 生成评估报告
12. 保存记录（包含简历数据）

## 注意事项

1. **无硬编码**：所有路径、配置均通过参数传递或从配置文件读取
2. **向后兼容**：现有代码和测试用例无需修改
3. **错误处理**：简历生成失败时会使用备用生成器
4. **数据隐私**：简历数据仅保存在本地文件系统
