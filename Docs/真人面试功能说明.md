# 真人面试功能说明

## 📌 功能概述

真人面试模块允许真实用户参与AI面试官主导的面试过程，提供完整的面试体验和专业的评估报告。

## ✨ 核心功能

### 1. **面试准备阶段**
- **领域选择**：支持技术、营销、医疗、供应链等多个专业领域
- **简历提交**：
  - 方式一：手动输入JSON格式简历
  - 方式二：简单描述背景，AI自动生成结构化简历
- **简历编辑**：生成后可在同一输入框中修改和完善

### 2. **面试进行阶段**
- **AI面试官**：
  - 基于RAG（检索增强生成）技术，利用历史面试经验提升专业水平
  - 根据简历生成针对性问题
  - 动态评估回答并决定是否追问
  
- **回答方式**：
  - **文字输入**：在文本框中输入回答
  - **语音输入**：
    - 点击🎤按钮开始录音
    - 说话完毕后停顿1-2秒（系统自动检测停顿）
    - 按钮变为⏹️，点击停止并识别
    - 识别的文字会自动追加到文本框中
  - **混合输入**：可以先输入部分文字，再使用语音补充，实现灵活的输入方式

- **实时评估**：
  - 每个回答后立即显示评分（0-100分标准化评分）
  - 多维度评估：技术深度、实践经验、回答具体性、逻辑清晰度、诚实度、沟通能力
  - 智能追问机制：检测到浮于表面或不确定的回答时，会进行深入追问

### 3. **面试完成阶段**
- **综合评估报告**：
  - 推荐度评分仪表盘
  - 多维度能力雷达图
  - 技能评分分布图
  - 优势与改进建议
  - 招聘建议

- **记录保存**：
  - 完整的面试对话记录
  - 评估结果和简历数据
  - 保存至 `data/interviews/` 目录

## 🎥 音视频功能

### 语音识别
- **当前功能**：将语音实时转换为文字
- **支持语言**：中文（zh-CN）
- **技术实现**：基于Google Speech Recognition API

### 摄像头录制
- **当前功能**：录制面试过程视频
- **预留接口**：
  - **测谎模型接口**：`register_lie_detection_model(callback)`
  - **大五人格识别模型接口**：`register_personality_detection_model(callback)`
- **录制格式**：AVI格式，保存至 `data/videos/` 目录

## 🔧 技术架构

### 核心模块
1. **面试官Agent** (`agents/interviewer_agent.py`)
   - 集成记忆系统（MemorySystem）
   - RAG增强的问题生成和评估
   - 智能追问机制

2. **音视频工具** (`core/audio_video_tools.py`)
   - `SpeechRecognizer`：语音识别器
   - `VideoRecorder`：视频录制器（含模型接口）
   - `AudioRecorder`：音频录制器

3. **简历生成** (`core/resume_generator.py`)
   - 基于用户描述生成结构化简历
   - 适配不同领域的职位要求

4. **评估可视化** (`frontend/visualizations.py`)
   - 评分仪表盘、雷达图、柱状图等

### 数据流
```
用户输入简历 → AI面试官生成问题 → 用户回答（文字/语音）
→ 实时评估 → 追问判断 → 最终报告 → 保存记录
```

## 🚀 使用流程

### 1. 启动应用
```bash
streamlit run app.py
```

### 2. 导航至真人面试页面
点击侧边栏的 "🎤 真人面试"

### 3. 准备简历
- **选项A**：直接输入JSON格式简历
- **选项B**：描述您的背景，让AI生成简历，然后在同一输入框中编辑

### 4. 配置选项
- 选择面试领域（技术/营销/医疗等）
- 启用记忆系统（推荐，让AI面试官更专业）
- 可选：启用摄像头录制

### 5. 开始面试
- 面试官提问后，在文本框中输入回答：
  - **纯文字**：直接在文本框输入后点击"📤 提交回答"
  - **纯语音**：
    1. 点击🎤按钮开始录音（环境噪音校准0.5秒）
    2. 对着麦克风说话
    3. 说完后停顿1-2秒（系统自动检测）
    4. 按钮变为⏹️，点击停止并识别
    5. 识别文字自动填入输入框
    6. 点击"提交回答"
  - **混合输入**：先输入部分文字，再点击🎤补充语音内容，可多次追加，最后提交

### 6. 查看评估
- 面试完成后自动生成综合评估报告
- 可查看推荐度、多维度评分、优势和改进建议

## 📊 评估标准

### 多维度评分（0-4分制）
1. **技术深度**：是否展示深入的技术理解
2. **实践经验**：是否有真实的项目经验
3. **回答具体性**：是否提供具体数据和案例
4. **逻辑清晰度**：思路是否清晰连贯
5. **诚实度**：是否坦诚、避免夸大
6. **沟通能力**：表达是否清晰有效

### 标准化评分（0-100分制）
- **0-40分**：不推荐
- **40-60分**：观察
- **60-80分**：推荐
- **80-100分**：强烈推荐

## 🐛 故障排查

### Streamlit自动终止
如果Streamlit在启动后立即终止：
1. 检查是否有Python语法错误
2. 查看控制台错误日志
3. 确保不要在页面加载时访问麦克风/摄像头（已修复）

### 语音识别不可用
1. 检查麦克风是否连接
2. 确认已安装 `SpeechRecognition` 和 `pyaudio`
3. Windows用户可能需要从whl安装pyaudio
4. 检查系统麦克风权限
5. 首次使用时浏览器/系统会请求权限

### 摄像头不可用
1. 检查摄像头是否连接
2. 确认已安装 `opencv-python`
3. 检查是否被其他程序占用
4. 检查系统摄像头权限

### 面试官回答质量低
1. 确认已启用记忆系统
2. 运行几次模拟面试积累经验
3. 检查领域配置是否正确

## 📝 注意事项

1. **隐私保护**：视频和音频记录仅保存在本地，不会上传
2. **网络要求**：语音识别需要网络连接（使用Google API）
3. **性能要求**：视频录制可能占用较多资源
4. **简历格式**：手动输入时需严格遵循JSON格式
5. **无硬编码**：所有配置均从文件或用户输入获取

## 🎙️ 语音输入工作流程

### 新版本（v1.1.0）- 手动控制
```
点击🎤按钮
   ↓
环境噪音校准（0.5秒）
   ↓
🎤 录音中... （按钮变为⏹️，可闪烁提示）
   ↓
用户说话
   ↓
用户停顿1-2秒
   ↓
系统自动检测到停顿，捕获音频
   ↓
提示：按钮保持⏹️，等待用户点击
   ↓
用户点击⏹️按钮
   ↓
发送到Google识别（需要网络）
   ↓
✅ 识别成功：[识别的文字]
   ↓
文字自动追加到输入框
   ↓
页面刷新，显示新内容
```

**优势**：
- ✅ 用户有手动控制感（点击开始、点击停止）
- ✅ 保留了停顿自动检测（不需要一直说话）
- ✅ 按钮状态清晰（🎤 ↔ ⏹️）
- ✅ 支持多次追加语音内容

## 🔧 已知问题与修复

### v1.1.0 (2024-11-28)
**改进**: 语音输入改为手动控制模式
- **变化**: 
  - 点击🎤开始录音，按钮变为⏹️
  - 说话完毕后停顿，系统自动捕获
  - 点击⏹️触发识别和文本追加
- **修复**: 
  - 修复了文本框同步问题（改用固定key）
  - 添加录音状态管理（is_recording）
  - 按钮图标动态切换（🎤 ↔ ⏹️）

### v1.0.1 (2024-11-28)
**问题**: Streamlit在启动后自动终止
- **原因**: `check_dependencies()`函数在页面加载时直接访问麦克风和摄像头硬件，在某些环境下会导致崩溃
- **修复**: 
  - 默认只检查库是否安装，不实际访问硬件设备
  - 添加`check_hardware`参数，允许在需要时才检查硬件
  - 增强错误处理，区分不同类型的错误
- **影响**: 设备状态显示改为"功能就绪"，实际设备可用性在首次使用时检测
