# 配置加载优化说明

## 问题描述

在 Streamlit 前端运行时，控制台会不断输出大量重复的配置加载日志：

```
2025-11-26 21:15:32.779 | INFO | domains:__init__:38 - 加载领域配置: marketing
2025-11-26 21:15:33.377 | INFO | domains:__init__:38 - 加载领域配置: marketing
2025-11-26 21:15:34.580 | INFO | domains:__init__:38 - 加载领域配置: marketing
...
```

## 根本原因

1. **重复创建实例**：每次创建 `InterviewerAgent` 时都会实例化新的 `DomainLoader`
2. **批量面试**：每个候选人都会创建新的面试引擎和 Agent
3. **无缓存机制**：没有复用已加载的配置

## 解决方案

### 1. 实现单例模式

为 `DomainLoader` 添加全局缓存和工厂方法：

```python
# 全局缓存
_DOMAIN_LOADER_CACHE = {}

class DomainLoader:
    @classmethod
    def get_instance(cls, domain_id: str = "tech") -> 'DomainLoader':
        """获取 DomainLoader 实例（单例模式）"""
        if domain_id not in _DOMAIN_LOADER_CACHE:
            _DOMAIN_LOADER_CACHE[domain_id] = cls(domain_id, _from_cache=False)
        return _DOMAIN_LOADER_CACHE[domain_id]
```

### 2. 更新所有调用点

将所有 `DomainLoader(domain_id)` 替换为 `DomainLoader.get_instance(domain_id)`：

**更新的文件：**
- ✅ `agents/interviewer_agent.py`
- ✅ `core/random_generator.py` (2处)
- ✅ `config/__init__.py`
- ✅ `domains/__init__.py`
- ✅ `frontend/interview_controller.py` (添加了额外的配置缓存)

### 3. 优化日志输出

- 只在**首次加载**时输出 INFO 级别日志
- 后续从缓存获取时不输出任何日志
- 添加 `✅ 首次加载领域配置` 标识

## 效果对比

### 优化前
```
每个候选人 → 创建新的 DomainLoader → 输出加载日志
批量10个候选人 → 10次日志输出
页面交互 → 可能触发额外的加载
```

### 优化后
```
首次使用某领域 → 创建并缓存 DomainLoader → 输出 "✅ 首次加载领域配置: xxx"
后续所有使用 → 直接从缓存获取 → 无日志输出
批量10个候选人 → 仅1次日志输出
```

## 性能提升

1. **减少磁盘I/O**：配置文件只读取一次
2. **减少内存分配**：复用同一个对象
3. **减少日志噪音**：控制台输出清晰
4. **提升响应速度**：避免重复初始化

## 使用示例

### 基本使用（自动缓存）
```python
# 推荐方式：使用单例模式
domain = DomainLoader.get_instance("marketing")

# 不推荐（仅测试时使用）：直接实例化
domain = DomainLoader("marketing")  
```

### 清空缓存（测试场景）
```python
from domains import clear_domain_cache

# 清空所有缓存，强制重新加载
clear_domain_cache()
```

## 兼容性

- ✅ **向后兼容**：旧的 `DomainLoader(domain_id)` 仍然可用
- ✅ **测试兼容**：测试代码无需修改即可运行
- ✅ **功能完整**：所有功能保持不变

## 维护建议

1. **新代码**：统一使用 `DomainLoader.get_instance()`
2. **测试代码**：可选择在 `setUp` 中调用 `clear_domain_cache()`
3. **监控**：关注首次加载日志，确保配置正确
