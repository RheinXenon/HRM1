# HRM1 智能面试系统 - 前端页面实现文档

## 📋 概述

本文档描述了HRM1智能面试系统基于Streamlit的前端实现，包括架构设计、功能模块、使用方法等。

## 🏗️ 架构设计

### 整体架构

```
HRM1/
├── app.py                          # 主页面入口
├── run_app.py                      # 一键启动脚本
├── pages/                          # 多页面应用
│   ├── 1_🎮_面试控制台.py         # 面试控制台页面
│   ├── 2_📊_历史记录.py           # 历史记录分析页面
│   └── 3_⚙️_域配置.py             # 域配置管理页面（开发中）
├── frontend/                       # 前端工具模块
│   ├── __init__.py
│   ├── interview_controller.py    # 面试控制器
│   ├── data_loader.py             # 数据加载器
│   └── visualizations.py          # 可视化工具
└── data/                          # 数据存储
    ├── interviews/                # 面试完整记录（JSON）
    ├── analysis/                  # 分析摘要数据
    └── resumes/                   # 候选人简历
```

### 技术栈

- **前端框架**: Streamlit 1.30.0
- **数据处理**: Pandas, NumPy
- **可视化**: Plotly
- **并发控制**: Threading, Queue
- **状态管理**: Streamlit Session State

## 🎨 页面功能

### 1. 主页 (app.py)

**功能概述**:
- 系统欢迎页面
- 功能特性介绍
- 系统概览统计
- 快速导航指引

**主要组件**:
- 渐变色标题横幅
- 三栏功能卡片（面试控制台、历史记录、域配置）
- 统计数据展示（总面试次数、平均评分、平均时长）
- 响应式布局设计

### 2. 面试控制台 (pages/1_🎮_面试控制台.py)

**核心功能**:

#### 2.1 配置区（侧边栏）
- **领域选择**: 技术、营销、医疗等多领域支持
- **面试模式**: Demo模式（3题）/ 完整模式（全部）
- **候选人配置**:
  - 模板候选人：6种预设模板（理想、初级、紧张、过度自信、过度谦虚、知识盲区测试）
  - 随机生成：4种策略（正态分布、平衡型、极端型、完全随机）+ 6种性格原型
- **批量模拟**: 支持批量数量设置（当前版本限制为1）

#### 2.2 控制面板
- **开始面试**: 启动面试流程
- **暂停**: 暂停当前面试
- **继续**: 从暂停处继续
- **中止**: 终止面试流程
- **状态显示**: 实时显示运行状态

#### 2.3 候选人信息卡片
- 姓名和基本信息
- 技能列表（进度条展示）
- 性格特征（大五人格）
- 简历预览

#### 2.4 面试对话区
- **实时流式输出**: 模拟真实面试的对话流
- **角色区分**: 
  - 👔 面试官消息（蓝色背景）
  - 👤 候选人消息（绿色背景）
  - 📢 系统消息（黄色背景）
- **追问标识**: 🔍 追问环节特殊标记
- **实时评分**: 每个回答后显示评分和建议

#### 2.5 最终评估报告
- **综合评分仪表盘**: 0-100分可视化展示
- **多维度雷达图**: 6个维度能力分析
- **技能评分柱状图**: Top 10技能排名
- **优势与改进**: 分栏展示
- **总结与建议**: 详细文字报告

**实现特点**:
- 多线程异步处理，避免界面阻塞
- 消息队列机制实现实时通信
- Session State管理复杂状态
- 自动刷新机制保持同步

## 🔧 核心模块

### InterviewController (interview_controller.py)

**职责**: 管理面试流程的启动、暂停、继续、中止

**主要方法**:
```python
start_interview(domain_id, candidate_config, mode, callback)
pause_interview()
resume_interview()
stop_interview()
get_message()  # 获取队列消息
```

**实现机制**:
- 独立线程运行面试流程
- 消息队列实现实时通信
- 事件标志控制暂停/停止
- Hook机制捕获对话内容

**消息类型**:
- `message`: 对话消息（面试官/候选人）
- `system`: 系统提示
- `evaluation`: 评分信息
- `candidate_info`: 候选人信息
- `resume`: 简历数据
- `interview_info`: 面试基本信息
- `final_report`: 最终评估报告
- `error`: 错误信息

### DataLoader (data_loader.py)

**职责**: 加载和解析历史数据

**主要方法**:
```python
load_all_interviews()           # 加载所有面试
load_interview_by_id(id)        # 加载特定面试
get_interviews_dataframe()      # 转换为DataFrame
get_statistics()                # 获取统计数据
search_interviews(...)          # 搜索过滤
export_to_csv(path)             # 导出CSV
```

**数据处理**:
- JSON文件解析
- Pandas数据转换
- 统计指标计算
- 多条件搜索

### Visualizations (visualizations.py)

**职责**: 生成各类数据可视化图表

**图表类型**:

1. **create_score_chart**: 评分仪表盘
   - 0-100分刻度
   - 分段颜色（红/橙/绿）
   - 参考线和阈值

2. **create_dimension_radar_chart**: 维度雷达图
   - 6个评估维度
   - 0-4分刻度
   - 填充区域展示

3. **create_timeline_chart**: 时间线图
   - 散点图展示
   - 时间轴
   - 气泡大小表示时长
   - 颜色梯度表示分数

4. **create_comparison_chart**: 对比柱状图
   - 多候选人横向对比
   - 分数颜色编码
   - 数值标注

5. **create_score_distribution_chart**: 分布饼图
   - 四档分类
   - 圆环图样式
   - 颜色区分

6. **create_dimension_comparison_chart**: 维度对比雷达图
   - 多候选人叠加
   - 最多5人对比
   - 不同颜色区分

7. **create_skills_bar_chart**: 技能柱状图
   - Top 10技能
   - 降序排列
   - 分数颜色编码

**设计原则**:
- 统一配色方案
- 支持中文字体
- 响应式尺寸
- 交互式图表

## 🚀 启动方式

### 方法1: 一键启动 (推荐)

```bash
python run_app.py
```

**特点**:
- 自动查找可用端口
- 自动打开浏览器
- 实时日志输出
- Ctrl+C优雅退出

### 方法2: 直接运行

```bash
streamlit run app.py
```

或指定端口:

```bash
streamlit run app.py --server.port 8501
```

### 访问地址

默认: `http://localhost:8501`

## 🎨 自定义样式

### CSS注入

所有页面通过 `st.markdown(..., unsafe_allow_html=True)` 注入自定义CSS:

```python
st.markdown("""
<style>
    .custom-class {
        /* 样式定义 */
    }
</style>
""", unsafe_allow_html=True)
```

### 常用样式类

- `.main-header`: 主标题渐变
- `.feature-card`: 功能卡片
- `.metric-card`: 指标卡片
- `.message-box`: 消息容器

## ⚡ 性能优化

### 数据缓存

使用Streamlit缓存机制:
```python

def load_data():
    # 数据加载逻辑
    pass
```

### 异步处理

- 面试流程在独立线程运行
- 避免阻塞主UI线程

## 🐛 已知限制

1. **批量模拟**: 当前版本仅支持单个候选人，批量功能开发中
2. **域配置**: 完整的域配置界面尚未实现
3. **实时刷新**: 使用 `st.rerun()` 可能导致闪烁
4. **长对话**: 超长对话记录可能影响页面性能
