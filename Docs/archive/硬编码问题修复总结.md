### 2. **InterviewerAgent评估函数**

**位置**: `agents/interviewer_agent.py` - `evaluate_answer()`

**问题**：
- 只传递了question/answer/target_skills
- 没有传递领域特定的信号词

**修复**：
```python
# 从domain获取信号词示例
high_level_terms = self.domain.get_high_level_terms()
technical_metrics = self.domain.get_technical_metrics()

# 构建提示语
high_level_hint = f"（如{', '.join(high_level_terms[:3])}等）" if high_level_terms else ""
metrics_hint = f"（如{', '.join(technical_metrics[:3])}等）" if technical_metrics else ""

# 动态传入prompt
user_message = ANSWER_EVALUATION_PROMPT.format(
    question=question,
    answer=answer,
    target_skills=", ".join(target_skills),
    high_level_terms_hint=high_level_hint,  # 新增
    metrics_hint=metrics_hint  # 新增
)
```

**效果**：
- LLM现在知道在healthcare领域应该关注"整体护理、循证护理"等术语
- 而不是只关注"微服务、分布式"等tech术语

### 6. **追问机制阈值优化**

**位置**: 
- `agents/interviewer_agent.py` - `detect_shallow_answer()`
- `core/interview_engine.py` - 追问判断逻辑

**问题**：
- 追问判断阈值偏高（suspicion_score需要>=4）
- 在非tech领域追问触发率很低

**修复**：

**规则检测阈值**：
```python
# 之前：suspicion_score >= 4
suspicious = suspicion_score >= 4

# 现在：suspicion_score >= 3（降低1分）
suspicious = suspicion_score >= 3
```

**综合判断阈值**：
```python
# 之前
should_followup = (
    (confidence_level == "overconfident" and need_followup_by_llm) or
    (detection["is_suspicious"] and normalized_score >= 50) or
    (detection.get("suspicion_score", 0) >= 3 and normalized_score >= 60)
)

# 现在：多层次判断
should_followup = (
    (confidence_level == "overconfident" and need_followup_by_llm) or
    (detection["is_suspicious"] and normalized_score >= 45) or  # 降低5分
    (detection.get("suspicion_score", 0) >= 3 and normalized_score >= 50) or  # 降低10分
    (detection.get("suspicion_score", 0) >= 2 and normalized_score >= 65)  # 新增：轻度可疑+高分
)
```

**效果**：
- 轻度可疑（suspicion_score=2）+ 高分（>=65）也会触发追问
- 中度可疑（suspicion_score=3）+ 中等分（>=50）触发追问
- 明显可疑（suspicion_score>=3）+ 中低分（>=45）触发追问
- 各领域追问触发率显著提高且更加均衡

## 🔧 技术实现细节

### 动态信号词传递流程

```
InterviewerAgent.evaluate_answer()
    ↓
从DomainLoader获取信号词
    - high_level_terms: ["整体护理", "循证护理", ...]
    - technical_metrics: ["血压", "心率", ...]
    ↓
构建提示语hint
    - high_level_hint = "（如整体护理, 循证护理, 护理诊断等）"
    - metrics_hint = "（如血压, 心率, 体温等）"
    ↓
传入ANSWER_EVALUATION_PROMPT
    ↓
LLM评估时知道该关注哪些专业术语
```

### 配置生成流程

```
generate_domain_config(domain_id="healthcare")
    ↓
加载domains/healthcare/domain_config.json
    - domain_name: "医疗/护理"
    - typical_roles: ["护士", ...]
    - applicable_industries: ["医院", ...]
    ↓
加载domains/healthcare/skills_taxonomy.json
    - skill_categories: {...}
    - soft_skills: {...}
    ↓
动态生成company_config和job_config
    - company_name: "仁心医疗机构"
    - job_title: "护士"
    - 必备技能: 从skills_taxonomy前2个类别选择
    - 加分技能: 从skills_taxonomy第3-4个类别选择
```
