# 自动面试系统 - 功能文档

> **项目定位**：基于LLM的自动面试模拟系统，候选人和面试官均由AI扮演
> 
> **核心创新**：候选人Agent具备预设能力画像和性格特质，可自主生成回答
> 
> **创建日期**：2025年11月

---

## 一、项目概述

### 1.1 核心特点
- **双Agent架构**：面试官Agent + 候选人Agent 完全自动化对话
- **可配置候选人**：预设技能水平、性格特质、经验背景
- **自主交互**：无需人工干预，自动完成完整面试流程
- **批量测试**：支持多候选人配置并行测试

### 1.2 应用场景
1. **面试系统测试**：验证面试官Agent的提问和评估质量
2. **训练数据生成**：自动生成大量面试对话数据
3. **候选人模型研究**：研究不同特质候选人的表现模式
4. **招聘流程优化**：测试不同面试策略的效果

## 二、核心功能模块

### 2.1 候选人Agent配置模块

#### 功能1：能力画像设定
**配置维度**：
- **技能等级**（每项技能1-10分）
  - 技术能力：编程语言、框架、工具等
  - 软技能：沟通、领导力、团队协作等
  - 领域知识：行业经验、专业知识等

- **经验背景**
  - 工作年限：1-20年
  - 项目经历：3-10个项目（自动生成或模板选择）
  - 职位级别：初级/中级/高级/专家

**配置方式**：
```json
{
  "skills": {
    "python": 8,
    "react": 6,
    "leadership": 7
  },
  "experience": {
    "years": 5,
    "level": "senior",
    "projects": ["project_template_1", "project_template_2"]
  }
}
```

#### 功能2：性格特质设定
**特质维度**（每项0-100）：
- **沟通风格**
  - verbose（啰嗦型）vs concise（简洁型）
  - technical（技术型）vs general（通俗型）
  
- **回答特征**
  - confidence（自信度）：影响回答的确定性
  - detail_orientation（细节倾向）：回答的详细程度
  - storytelling（叙事能力）：使用STAR方法的倾向
  
- **情绪特征**
  - nervousness（紧张度）：影响回答的犹豫和修正
  - enthusiasm（热情度）：影响语气和积极性

**配置示例**：
```json
{
  "personality": {
    "communication": {
      "verbose": 70,
      "technical": 80
    },
    "response": {
      "confidence": 85,
      "detail_orientation": 75,
      "storytelling": 60
    },
    "emotion": {
      "nervousness": 20,
      "enthusiasm": 80
    }
  }
}
```

#### 功能3：候选人模板库
**预置模板**（5-10个典型候选人）：
1. **理想候选人**：技能优秀、性格平衡、经验丰富
2. **初级新手**：技能基础、热情高、经验少
3. **技术大牛**：技术顶尖、沟通一般、不善社交
4. **啰嗦型**：回答冗长、跑题、缺乏重点
5. **紧张型**：能力可以、但表达犹豫、信心不足
6. **傲慢型**：能力强、但态度问题、团队配合差

### 2.2 面试官Agent模块

#### 功能4：面试脚本生成
**输入**：
- 职位描述
- 公司信息
- 候选人配置（用于匹配问题难度）

**生成内容**：
- 4类问题（职位/技术/文化/行为）
- 每类2-5题（根据模式调整）
- 动态难度调整（基于候选人能力）

#### 功能5：智能追问与评估
**功能复用**：
- 借鉴原系统的追问机制
- 回答质量评估（1-10分）
- 动态追问决策

---

### 2.3 候选人Agent回答生成模块

#### 功能6：基于能力的回答生成
**生成逻辑**：
```
IF 问题涉及技能X:
    IF 候选人技能等级[X] >= 7:
        生成深入、专业的回答（含技术细节）
    ELIF 候选人技能等级[X] >= 4:
        生成基础、合理的回答（理论为主）
    ELSE:
        生成模糊、浅显的回答（缺少细节）
```

**Prompt结构**：
```
你是一位候选人，正在参加面试。

你的能力画像：
- Python: 8/10（精通）
- React: 6/10（熟悉）
- Leadership: 7/10（良好）

你的工作经历：
- 5年软件开发经验
- 担任过Tech Lead角色
- 完成过3个大型项目

你的性格特质：
- 沟通风格：技术型、简洁型
- 自信度：85/100
- 紧张度：20/100

面试官问题：{question}

请基于你的能力和性格生成回答：
- 如果问题涉及你擅长的领域，展示专业知识和具体经验
- 如果问题超出你的能力范围，诚实承认并表达学习意愿
- 回答风格符合你的性格特质
- 回答长度：50-150词（根据verbose参数调整）
```

#### 功能7：性格驱动的回答风格
**风格控制**：
- **verbose高** → 回答长、包含冗余信息、可能跑题
- **technical高** → 使用专业术语、技术细节丰富
- **confidence低** → 使用"我觉得"、"可能"等不确定词汇
- **nervousness高** → 回答中有停顿标记、自我修正
- **storytelling高** → 使用STAR格式、讲述具体案例

**示例**：
```
高自信、简洁、技术型：
"我在过去3年主导了微服务架构的改造，使用K8s实现了容器编排，
系统吞吐量提升了3倍，同时将部署时间从2小时缩短到15分钟。"

低自信、啰嗦、紧张型：
"嗯...关于微服务，我觉得...应该说我有一些经验吧。之前在公司，
就是...那个项目，我们好像是用了Docker，或者说类似的技术？
具体的细节我可能需要想一下...不过我记得最后效果还不错。"
```

#### 功能8：候选人主动提问
**提问时机**：
- 面试结束前（"您有什么问题吗？"）
- 随机插入（基于enthusiasm参数）

**提问内容**：
- 基于候选人的兴趣和性格生成
- 问题质量与能力等级相关

### 2.4 自动化面试执行模块

#### 功能9：完整对话流程
```
[初始化]
    ↓
[加载职位、公司、候选人配置]
    ↓
[生成面试脚本]
    ↓
[开场白] ← 面试官Agent
    ↓
[自我介绍] ← 候选人Agent
    ↓
FOR 每个问题:
    [提问] ← 面试官Agent
    ↓
    [生成回答] ← 候选人Agent
    ↓
    [评估质量] ← 面试官Agent
    ↓
    IF 需要追问:
        [追问] ← 面试官Agent
        ↓
        [补充回答] ← 候选人Agent
    ↓
[结束语+候选人提问环节]
    ↓
[生成评估报告]
    ↓
[保存完整记录]
```

#### 功能10：批量执行与并行
**批量测试**：
- 一次配置多个候选人
- 同一职位多候选人对比
- 并行执行多场面试（限并发数）

**执行参数**：
```json
{
  "job_id": "senior_dev_001",
  "candidates": [
    {"id": "candidate_1", "template": "ideal"},
    {"id": "candidate_2", "template": "nervous"},
    {"id": "candidate_3", "config": {...}}
  ],
  "parallel": true,
  "max_concurrent": 3
}
```

### 2.5 数据分析模块

#### 功能11：单场面试分析
**分析维度**（继承原系统）：
- 技能评分
- 优势/改进
- 招聘建议
- 推荐度评分

#### 功能12：多候选人对比
**对比视图**：
```
┌─────────────┬──────────┬──────────┬──────────┐
│  维度       │ 候选人A  │ 候选人B  │ 候选人C  │
├─────────────┼──────────┼──────────┼──────────┤
│ Python技能  │   8.5    │   6.0    │   7.2    │
│ 沟通能力    │   7.0    │   5.5    │   8.0    │
│ 推荐度      │   85     │   65     │   78     │
│ 总评        │  强推荐  │  中性    │  推荐    │
└─────────────┴──────────┴──────────┴──────────┘
```

#### 功能13：候选人特质影响分析
**研究问题**：
- 哪些性格特质对面试结果影响最大？
- 技能水平与最终评分的相关性？
- 不同面试官策略对不同候选人的效果？

**输出**：
- 相关性矩阵
- 特质权重分析
- 最优候选人画像

## 五、与原系统的差异

| 维度 | 原系统 | 新系统 |
|------|--------|--------|
| **候选人** | 真人用户 | AI Agent |
| **交互方式** | 等待用户输入 | 自动生成回答 |
| **执行模式** | 单次面试 | 批量并行 |
| **主要目的** | 面试模拟练习 | 系统测试&数据生成 |
| **评估对象** | 候选人表现 | 面试系统质量 |

## 六、扩展方向

### 可能的创新功能
1. **动态难度调整**：面试官根据候选人表现实时调整问题难度
2. **多轮面试**：初面、二面、终面完整流程
3. **面试官多样性**：不同风格的面试官（友好型/严厉型/技术型）
4. **学习与进化**：候选人Agent从面试中学习，改进回答策略
5. **对抗训练**：训练候选人Agent应对不同面试官策略

### 研究价值
- **面试有效性研究**：哪些问题最能区分候选人能力？
- **评估公平性**：系统对不同性格候选人是否公平？
- **最优面试策略**：多少追问？什么顺序最有效？
