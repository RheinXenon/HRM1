# 随机性格系统使用指南

## 📌 功能概述

随机性格系统允许每次面试时自动生成不同的候选人性格特质，无需使用固定模板，极大增加了测试的多样性和真实性。

## 🎲 核心特性

### 1. **完全随机生成**
- 每次运行都生成全新的性格特质
- 不依赖固定模板配置
- 可选保存优秀的生成结果

### 2. **多种生成策略**
支持 4 种不同的生成策略：

| 策略 | 描述 | 适用场景 |
|------|------|----------|
| `normal` | 正态分布（推荐） | 模拟真实人群分布，最常用 |
| `balanced` | 平衡型 | 所有参数接近中间值，测试标准情况 |
| `extreme` | 极端型 | 更容易出现极值，测试边界情况 |
| `uniform` | 完全随机 | 均匀分布，探索所有可能性 |

### 3. **预设性格原型**
支持 6 种性格原型（带随机波动）：

| 原型 | 特征 | 典型表现 |
|------|------|----------|
| `confident` | 自信型 | 自信度高，紧张度低，回答坚定 |
| `nervous` | 紧张型 | 紧张度高，自信度低，回答犹豫 |
| `technical` | 技术型 | 技术用词多，细节丰富，较严谨 |
| `storyteller` | 叙事型 | 善用 STAR 方法，故事性强 |
| `enthusiastic` | 热情型 | 热情度高，语气积极，表达生动 |
| `reserved` | 保守型 | 简洁表达，较为低调 |

## 🚀 快速开始

### 方法 1：命令行模式（推荐）

```bash
# 运行随机性格面试
python main.py --mode random
```

运行后会看到交互式菜单：

```

1. normal - 正态分布（推荐，更真实）
2. balanced - 平衡型（中等值）
3. extreme - 极端型（有趣的边界情况）
4. uniform - 完全随机

可选的性格原型:
5. confident - 自信型
6. nervous - 紧张型
7. technical - 技术型
8. storyteller - 叙事型
9. enthusiastic - 热情型
10. reserved - 保守型

请选择 (1-10, 默认1):
```

### 方法 2：Python 脚本调用

```python
from core.personality_generator import PersonalityGenerator, create_random_candidate_config
from core import InterviewEngine

# 生成随机候选人配置
candidate_config = create_random_candidate_config(
    base_template="ideal_candidate",
    personality_strategy="normal"  # 可选：normal/balanced/extreme/uniform
)

# 执行面试
engine = InterviewEngine()
result = engine.run_interview(
    job_file="senior_backend",
    company_file="tech_startup",
    candidate_config=candidate_config,
    mode="demo"
)

print(f"推荐度: {result.recommendation_score}/100")
```

### 方法 3：仅生成性格（不面试）

```python
from core.personality_generator import PersonalityGenerator

# 创建生成器
generator = PersonalityGenerator(seed=42)  # seed 可选，用于复现

# 随机生成
personality = generator.generate_random("normal")

# 或使用原型
personality = generator.generate_archetype("confident")

# 查看结果
print(personality.to_dict())
```

## 📊 性格参数说明

### 沟通风格 (communication)

- **verbose** (20-90)：啰嗦程度
  - 低值：简洁型，回答简短直接
  - 高值：详细型，回答详尽全面

- **technical** (30-95)：技术用词程度
  - 低值：通俗表达，更多业务语言
  - 高值：专业术语，技术细节丰富

### 回答特征 (response)

- **confidence** (30-95)：自信度
  - 低值：犹豫不决，语气不确定
  - 高值：肯定自信，表达坚定

- **detail_orientation** (30-90)：细节倾向
  - 低值：宏观描述，重点突出
  - 高值：细节丰富，面面俱到

- **storytelling** (20-85)：叙事能力
  - 低值：直接陈述事实
  - 高值：善用 STAR 方法讲故事

### 情绪特征 (emotion)

- **nervousness** (5-70)：紧张度
  - 低值：从容淡定
  - 高值：紧张焦虑，可能出现口误

- **enthusiasm** (30-95)：热情度
  - 低值：平淡冷静
  - 高值：热情洋溢，积极向上

## 🔧 高级用法

### 1. 批量生成测试不同性格

```python
from core.personality_generator import create_random_candidate_config
from core import InterviewEngine

engine = InterviewEngine()
strategies = ["normal", "extreme", "balanced"]

results = []
for strategy in strategies:
    for i in range(5):  # 每种策略生成5个
        candidate = create_random_candidate_config(
            personality_strategy=strategy
        )
        result = engine.run_interview(
            job_file="senior_backend",
            company_file="tech_startup",
            candidate_config=candidate,
            mode="demo"
        )
        results.append({
            "strategy": strategy,
            "score": result.recommendation_score,
            "name": candidate['profile']['name']
        })

# 分析结果
for r in sorted(results, key=lambda x: x['score'], reverse=True)[:5]:
    print(f"{r['name']}: {r['score']} (策略: {r['strategy']})")
```

### 2. 保存喜欢的性格配置

在命令行模式下，系统会询问是否保存生成的配置：

```
是否保存此性格配置？(y/N): y
输入文件名（不含扩展名）: creative_candidate_1

✅ 配置已保存至: config/candidate_templates/generated/creative_candidate_1.json
```

之后可以通过模板方式使用：

```python
from config import load_candidate_template

# 加载保存的配置
candidate = load_candidate_template("generated/creative_candidate_1")
```

### 3. 使用随机种子复现结果

```python
from core.personality_generator import PersonalityGenerator

# 使用相同的种子会生成相同的性格
generator1 = PersonalityGenerator(seed=12345)
personality1 = generator1.generate_random("normal")

generator2 = PersonalityGenerator(seed=12345)
personality2 = generator2.generate_random("normal")

# personality1 和 personality2 完全一致
assert personality1.to_dict() == personality2.to_dict()
```

### 4. 自定义原型

可以扩展 `PersonalityGenerator.generate_archetype()` 方法添加自定义原型：

```python
# 在 personality_generator.py 的 archetypes 字典中添加
"perfectionist": {
    "communication": {"verbose": 85, "technical": 95},
    "response": {"confidence": 70, "detail_orientation": 95, "storytelling": 60},
    "emotion": {"nervousness": 40, "enthusiasm": 65}
}
```

## 💡 最佳实践

### 1. **选择合适的策略**
- 日常测试：使用 `normal` 策略
- 压力测试：使用 `extreme` 策略测试边界情况
- 标准测试：使用 `balanced` 策略建立基线

### 2. **保存优秀配置**
- 遇到表现特别好或特别差的候选人，记得保存配置
- 用于后续对比测试和问题复现

### 3. **批量测试建议**
- 每种策略至少测试 10 次以上
- 记录各策略的平均推荐度
- 分析性格参数与面试结果的相关性

### 4. **组合使用**
```python
# 混合使用固定模板和随机性格
base_templates = ["ideal_candidate", "junior_candidate", "nervous_candidate"]
strategies = ["normal", "extreme"]

for template in base_templates:
    for strategy in strategies:
        candidate = create_random_candidate_config(
            base_template=template,
            personality_strategy=strategy
        )
        # ... 执行面试
```

## 🐛 常见问题

### Q1: 生成的性格是否会影响技能评分？
A: 会的。性格特质会影响候选人的表达方式，进而影响面试官的评估。例如：
- 高自信度 + 低紧张度 → 可能获得更高评分
- 高技术性 + 高细节度 → 技术问题回答更专业

### Q2: 如何确保生成的性格合理？
A: 系统对每个参数都设置了合理范围：
- 紧张度最高 70（避免过度紧张）
- 自信度最低 30（保证基本自信）
- 所有参数都经过真实面试场景验证

### Q3: 可以完全自定义性格参数吗？
A: 可以！直接修改候选人配置中的 `personality` 字段：

```python
candidate_config['profile']['personality'] = {
    "communication": {"verbose": 70, "technical": 90},
    "response": {"confidence": 85, "detail_orientation": 80, "storytelling": 60},
    "emotion": {"nervousness": 20, "enthusiasm": 75}
}
```

### Q4: 随机性格会不会导致结果不稳定？
A: 这正是随机性格的目的 —— 测试系统在各种情况下的表现。如需稳定结果：
- 使用固定的 `seed` 参数
- 或使用固定模板而非随机生成
