# 面试官Agent追问能力改进报告

## 📋 改进目标

提升面试官Agent识别和验证候选人真实水平的能力，特别是针对**过度自信/不懂装懂**的候选人，通过智能追问机制挖掘其实际能力。

---

## 🔧 核心改进内容

### 1. 增强评估提示词（`interviewer_prompts.py`）

**改进点：**
- 在`ANSWER_EVALUATION_PROMPT`中增加**过度自信信号识别**指导
- 新增`confidence_level`字段（genuine/uncertain/overconfident）
- 新增`detail_score`字段评估回答细节丰富度
- 明确评分指导原则，防止被高级术语迷惑

**关键改进：**
```python
# 新增过度自信信号清单
- 使用高级术语但缺乏具体细节
- 回答模糊、使用大量不确定词汇
- 主动承认"记不清"但仍给出笼统回答
- 提到技术概念但没有具体数据、指标或代码示例
- 回答过短（<150字）但谈论复杂话题
- 缺乏对技术方案trade-off的深入思考
```

### 2. 改进浅层回答检测逻辑（`interviewer_agent.py`）

**改进点：**
- 引入`suspicion_score`可疑度评分系统（0-10分）
- 扩展高级术语词库，增加"容器"、"负载均衡"、"熔断"等
- 新增空话套话检测
- 更精细的评分阈值（可疑度≥4触发追问）

**核心逻辑：**
```python
# 多维度可疑信号检测
1. 高级术语但缺乏深度 → +3分
2. 多个技术概念但回答短 → +2分
3. 模糊词汇过多 → +2分
4. 回答过短但得分高 → +3分
5. 缺少量化指标 → +2分
6. 缺乏具体示例 → +2分
7. 明确承认不熟悉 → +3分
8. 空话套话多 → +1分

# 可疑度≥4 → 触发追问
```

### 3. 智能追问问题生成（`interviewer_agent.py` + `interviewer_prompts.py`）

**改进点：**
- 使用LLM智能生成追问问题（替代模板匹配）
- 新增`FOLLOW_UP_PROMPT`包含6大追问策略
- 追问问题基于候选人回答中的具体技术点
- 降级机制：LLM失败时使用备用模板

**追问策略：**
1. **要求具体化** - 具体参数、指标、代码示例
2. **深入原理** - 底层实现、工作机制、源码细节
3. **实战问题** - 项目中的具体问题和解决方案
4. **边界情况** - 异常、性能瓶颈、容错处理
5. **技术对比** - 方案优劣、trade-off分析
6. **量化指标** - 性能数据、并发量、响应时间

### 4. 优化追问触发条件（`interview_engine.py`）

**改进点：**
- 综合LLM评估和规则检测
- 降低追问门槛（可疑度≥3或得分≥6即可触发）
- 支持多次追问（不限制次数）

**触发逻辑：**
```python
should_followup = (
    (confidence_level == "overconfident" and need_followup_by_llm) or
    (detection["is_suspicious"] and score >= 5) or
    (detection["suspicion_score"] >= 3 and score >= 6)
)
```

### 5. 增强最终报告对追问结果的敏感度（`interviewer_prompts.py`）

**改进点：**
- 在`FINAL_REPORT_PROMPT`中强调**追问结果权重最高**
- 明确评分降低规则：每次"追问后露怯" → 推荐度降低15-25分
- 新增`overconfidence_detected`字段
- 推荐度评分指导原则

**评分指导：**
- **强烈推荐（90-100）**：全面优秀，追问后依然扎实
- **推荐（75-89）**：整体合格，追问中表现稳定
- **观察（60-74）**：基本达标或出现1次追问露怯
- **不推荐（<60）**：能力不足或出现2次及以上追问露怯

## 💡 关键技术亮点

### 1. 双层检测机制
- **LLM层**：语义理解，识别自信程度
- **规则层**：模式匹配，量化可疑信号
- **结合优势**：互为补充，提升准确率

### 2. 智能追问生成
- 基于LLM动态生成，非固定模板
- 针对候选人实际回答内容
- 6大策略确保追问深度

### 3. 追问结果优先原则
- 最终评分优先采用追问后分数
- "追问后露怯"作为严重负面信号
- 推荐度计算考虑追问表现

### 4. 可疑度评分系统
- 多维度信号累积（8个维度）
- 阈值触发（≥4分认为可疑）
- 可解释性强（明确哪些信号触发）
