# 大五人格系统使用指南

## 概述

本项目已完全重构为基于**大五人格模型（Big Five Personality Model）**的人格评估系统。该系统支持：

1. 内部随机生成大五人格数据
2. 从外部人格评估模型导入数据
3. 基于人格特质生成面试候选人行为

## 大五人格维度说明

所有人格维度分数范围：**0.0 - 1.0**

| 维度 | 英文名 | 说明 | 高分特征 | 低分特征 |
|------|--------|------|----------|----------|
| **开放性** | Openness | 好奇心、想象力、对新体验的开放程度 | 富有创造力，喜欢尝试新方法 | 偏好传统方法，倾向实用方案 |
| **尽责性** | Conscientiousness | 组织性、可靠性、自律性 | 非常有组织，注重细节 | 较为灵活变通，组织性较弱 |
| **外向性** | Extraversion | 社交性、活力、主导性 | 表达积极热情，交流主动 | 较为内敛，表达谨慎保守 |
| **宜人性** | Agreeableness | 合作性、信任、同情心 | 非常友善合作，倾向认同他人 | 更直接坦率，有明确观点 |
| **神经质** | Neuroticism | 情绪不稳定性、焦虑、易激动 | 较为焦虑紧张，缺乏自信 | 情绪稳定，表现自信镇定 |

## 使用方式

### 1. 从外部人格评估模型导入数据

这是**主要使用场景**。当你的外部模型完成面试者的人格评估后，可以直接导入结果：

```python
from core.personality_generator import PersonalityConfig

# 外部模型返回的评估结果（支持中英文标签）
external_model_results = {
    "openness": 0.75,
    "conscientiousness": 0.82,
    "extraversion": 0.65,
    "agreeableness": 0.58,
    "neuroticism": 0.35
}

# 方式1: 使用英文标签
personality = PersonalityConfig.from_external_model(external_model_results)

# 方式2: 使用中文标签
external_model_results_cn = {
    "开放性": 0.68,
    "尽责性": 0.72,
    "外向性": 0.55,
    "宜人性": 0.78,
    "神经质": 0.42
}
personality = PersonalityConfig.from_external_model(external_model_results_cn)

# 转换为字典格式用于候选人配置
personality_dict = personality.to_dict()
print(personality_dict)
# 输出: {
#   "openness": 0.68,
#   "conscientiousness": 0.72,
#   "extraversion": 0.55,
#   "agreeableness": 0.78,
#   "neuroticism": 0.42
# }
```

### 2. 在候选人配置中使用

```python
from agents.candidate_agent import CandidateAgent
from core.candidate_profile import CandidateProfile

# 创建候选人配置
candidate_config = {
    "template_name": "外部模型候选人",
    "profile": {
        "name": "张三",
        "skills": {
            "python": 8,
            "system_design": 7,
            "communication": 8
        },
        "experience": {
            "years": 5,

            "openness": 0.75,

    }

# 候选人会根据大五人格特质表现出相应的行为风格
```

### 3. 内部随机生成（用于测试）

```python
from core.personality_generator import PersonalityGenerator

generator = PersonalityGenerator(seed=42)  # 可选：设置种子以便复现

# 策略1: 正态分布（默认，最接近真实人群）
personality = generator.generate_random("normal")

# 策略2: 平衡型（所有维度接近0.5）
personality = generator.generate_random("balanced")

# 策略3: 极端型（容易出现极值）
personality = generator.generate_random("extreme")

# 策略4: 均匀分布（完全随机）
personality = generator.generate_random("uniform")

# 使用预设原型
archetypes = ["confident", "anxious", "creative", "reliable", "friendly", "analytical"]
personality = generator.generate_archetype("confident")
```

## 人格特质如何影响面试行为

### 开放性 (Openness)
- **高 (>0.7)**: 更愿意讨论创新方案、新技术，使用想象力和创造性思维
- **低 (<0.4)**: 偏好传统稳定方案，关注实用性和可靠性

### 尽责性 (Conscientiousness)
- **高 (>0.7)**: 回答更有条理，注重细节和准确性，系统化地组织答案
- **低 (<0.4)**: 较为灵活，但可能在组织性和细节方面较弱

### 外向性 (Extraversion)
- **高 (>0.7)**: 表达更积极热情，主动沟通，语言有活力
- **低 (<0.4)**: 较为内敛，表达谨慎保守，回答简洁

### 宜人性 (Agreeableness)
- **高 (>0.7)**: 更友善配合，倾向认同面试官观点，避免冲突
- **低 (<0.4)**: 更直接坦率，有自己明确的观点，可能挑战面试官

### 神经质 (Neuroticism)
- **高 (>0.7)**: 表现焦虑紧张，可能有停顿、自我修正、缺乏自信
- **低 (<0.4)**: 情绪稳定，表现自信镇定

## 知识盲区生成（自动推断）

系统会根据大五人格特质自动推断候选人的知识盲区倾向：

- **尽责性低 + 神经质低** → 容易过度自信（不懂装懂）
- **尽责性高 + 神经质高** → 容易过度谦虚（低估自己）
- **尽责性高 + 神经质适中** → 自我认知准确（很少盲区）

```python
from core.random_generator import RandomGenerator

generator = RandomGenerator()

skills = {"python": 7, "react": 4, "system_design": 6}

personality = {
    "openness": 0.65,
    "conscientiousness": 0.40,  # 低尽责性
    "extraversion": 0.75,
    "agreeableness": 0.50,
    "neuroticism": 0.30  # 低神经质
}

# 会倾向于生成"过度自信"的知识盲区
blind_spots = generator.generate_knowledge_blind_spots(skills, personality)
```

## 完整示例：对接外部评估模型

```python
from core.personality_generator import PersonalityConfig
from agents.candidate_agent import CandidateAgent
from core.candidate_profile import CandidateProfile

# 步骤1: 从你的外部人格评估模型获取结果
external_assessment_result = your_model.assess_personality(interview_data)
# 假设返回: {"openness": 0.72, "conscientiousness": 0.68, ...}

# 步骤2: 导入到系统
personality = PersonalityConfig.from_external_model(external_assessment_result)

# 步骤3: 创建候选人配置
candidate_config = {
    "template_name": "评估候选人",
    "profile": {
        "name": "候选人姓名",
        "skills": {...},
        "experience": {...},
        "personality": personality.to_dict(),  # 使用外部评估的人格数据
        "knowledge_blind_spots": None  # 可选：让系统自动生成
    }
}

# 步骤4: 使用候选人进行面试模拟
profile = CandidateProfile.from_dict(candidate_config)
candidate = CandidateAgent(profile)

# 候选人的回答会反映外部模型评估的人格特质
answer = candidate.answer_question("请介绍一下你的项目经验")
```

## 注意事项

1. **分数范围**: 所有人格维度分数必须在 0.0-1.0 之间
2. **标签兼容**: 系统同时支持中英文标签，会自动识别和转换
3. **缺失维度**: 如果外部模型只返回部分维度，缺失维度将使用默认值 0.5
4. **行为一致性**: 候选人的面试行为会严格遵循设定的人格特质
5. **知识盲区**: 可以手动指定或让系统根据人格特质自动生成

## 技术架构

```
外部人格评估模型
    ↓
PersonalityConfig.from_external_model()  # 导入接口
    ↓
CandidateProfile (包含大五人格数据)
    ↓
CandidateAgent (根据人格生成面试行为)
    ↓
面试对话系统
```
