# 人格系统重构说明

## 重构概述

项目人格系统已从自定义多维度模型**完全重构**为标准的**大五人格模型（Big Five Personality Model / OCEAN）**。


## 映射关系

旧系统维度如何映射到新系统：

| 旧维度 | 值范围 | 映射到新维度 | 映射逻辑 |
|--------|--------|--------------|----------|
| `communication.verbose` | 0-100 | `extraversion` + `conscientiousness` | 高外向性和尽责性 → 详细表达 |
| `communication.technical` | 0-100 | `openness` + `conscientiousness` | 高开放性和尽责性 → 技术性强 |
| `response.confidence` | 0-100 | `extraversion` - `neuroticism` | 高外向性低神经质 → 自信 |
| `response.detail_orientation` | 0-100 | `conscientiousness` | 高尽责性 → 注重细节 |
| `response.storytelling` | 0-100 | `extraversion` + `agreeableness` | 高外向性和宜人性 → 善于叙事 |
| `emotion.nervousness` | 0-100 | `neuroticism` | 直接对应 |
| `emotion.enthusiasm` | 0-100 | `extraversion` | 直接对应 |
| `self_perception.self_awareness` | 0-100 | `conscientiousness` × (1 - `neuroticism`) | 尽责性高神经质低 → 自知准确 |

## 新功能

### 1. 外部模型对接

```python
from core.personality_generator import PersonalityConfig

# 从外部人格评估模型导入
external_results = {
    "openness": 0.75,
    "conscientiousness": 0.82,
    "extraversion": 0.65,
    "agreeableness": 0.58,
    "neuroticism": 0.35
}

personality = PersonalityConfig.from_external_model(external_results)
```

### 2. 支持中英文标签

系统自动识别中文和英文标签：
- 英文：`openness`, `conscientiousness`, `extraversion`, `agreeableness`, `neuroticism`
- 中文：`开放性`, `尽责性`, `外向性`, `宜人性`, `神经质`

### 3. 自动边界处理

- 超出范围的值自动限制在 0.0-1.0
- 缺失的维度使用默认值 0.5

### 4. 知识盲区智能生成

基于大五人格特质自动推断：
- **尽责性低 + 神经质低** → 过度自信（不懂装懂）
- **尽责性高 + 神经质高** → 过度谦虚（低估自己）
- **尽责性高 + 神经质适中** → 自我认知准确

### 知识盲区生成逻辑对比

**旧系统:**
```python
if self_awareness < 40:
    # 低自知 -> 过度自信
elif self_awareness > 70:
    # 高自知 -> 过度谦虚
```

**新系统:**
```python
# 基于尽责性和神经质计算倾向
overconfidence_tendency = (1 - conscientiousness) * (1 - neuroticism)
underconfidence_tendency = conscientiousness * neuroticism

if overconfidence_tendency > 0.5:
    # 容易过度自信（不懂装懂）
elif underconfidence_tendency > 0.5:
    # 容易过度谦虚（低估自己）
```
