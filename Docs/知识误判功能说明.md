# 知识误判功能说明

## 概述

该功能模拟现实面试中候选人对自己能力的**误判**情况，包括：
- **不懂装懂**：对不熟悉的领域表现得过度自信，给出错误或片面的答案
- **过度谦虚**：对擅长的领域过度低估自己，显得不确定和犹豫

## 核心机制

### 1. 自知之明（Self-Awareness）

在性格配置中新增 `self_perception.self_awareness` 维度（20-95）：

- **< 50**: 容易「不懂装懂」
  - 对不熟悉的领域也会表现得很自信
  - 可能给出错误或片面的答案
  - 不太会承认自己不确定

- **50-70**: 准确认知自己的能力边界
  - 擅长的领域展示信心
  - 不熟悉的领域诚实承认

- **> 70**: 容易「过度谦虚」
  - 即使擅长的领域也会说"不太确定"
  - 频繁使用"我觉得"、"可能"等词汇
  - 过度强调还需要学习

### 2. 知识盲区（Knowledge Blind Spots）

在候选人配置中新增 `knowledge_blind_spots` 字段：

```json
"knowledge_blind_spots": {
  "overconfident_areas": [
    {
      "skill": "system_design",
      "actual_level": 5,
      "perceived_level": 8,
      "description": "对分布式系统有基本了解，但缺乏大规模实战经验，容易高估架构能力"
    }
  ],
  "underconfident_areas": [
    {
      "skill": "react",
      "actual_level": 8,
      "perceived_level": 5,
      "description": "有扎实的React项目经验，但总觉得理解不够深入"
    }
  ]
}
```

## 使用示例

### 示例1：过度自信候选人（不懂装懂）

**配置文件**: `config/candidate_templates/overconfident_candidate.json`

**特点**:
- 自知之明: 30/100（低）
- 实际能力: React 3/10，但自我感觉 7/10
- 面试表现: 即使对React不熟悉，也会自信地谈论hooks、性能优化等高级话题

**使用场景**:
- 测试面试官识别"不懂装懂"的能力
- 研究如何通过追问暴露候选人的知识漏洞
- 训练评估系统识别过度自信的信号

### 示例2：过度谦虚候选人（低估能力）

**配置文件**: `config/candidate_templates/underconfident_candidate.json`

**特点**:
- 自知之明: 85/100（高）
- 实际能力: System Design 8/10，但自我感觉 6/10
- 面试表现: 即使在系统设计方面有丰富经验，也会说"我不太确定"、"可能需要更多学习"

**使用场景**:
- 测试面试官挖掘候选人真实能力的技巧
- 研究如何让谦虚的候选人充分展示实力
- 识别有潜力但不善于表达的候选人

## 行为逻辑

### Agent回答策略

当候选人Agent收到问题时，会按以下逻辑处理：

```
1. 检查问题涉及的技能
2. 查看该技能是否在知识盲区中

3. 如果在"过度自信"盲区:
   → 即使实际能力不足，也表现得很自信
   → 给出听起来专业但实际不够准确的回答
   → 使用技术术语，但理解可能浮于表面
   → 不承认自己不确定

4. 如果在"过度谦虚"盲区:
   → 即使实际能力很强，也表现得犹豫、不确定
   → 使用"我觉得"、"可能"、"不太确定"等词汇
   → 过度强调还需要学习
   → 淡化自己的成就

5. 如果不在盲区:
   → 根据实际技能水平正常回答
   → 结合self_awareness调整表达方式
```

3. `underconfident_candidate` - 过度谦虚型

## 配置指南

### 创建自定义候选人

1. 复制现有模板文件
2. 调整 `self_perception.self_awareness` 值
3. 配置 `knowledge_blind_spots` 字段
4. 指定过度自信或过度谦虚的技能领域

### 参数调优建议

| 目标行为 | self_awareness | 盲区配置 |
|---------|----------------|---------|
| 不懂装懂 | 20-40 | overconfident_areas中指定技能 |
| 过度谦虚 | 75-90 | underconfident_areas中指定技能 |
| 准确认知 | 50-70 | 不配置或留空 |

## 评估应用

该功能可用于：

1. **面试官培训**
   - 识别候选人的不懂装懂行为
   - 学习如何挖掘谦虚候选人的真实能力

2. **评估系统优化**
   - 训练模型识别能力误判信号
   - 开发更准确的能力评估算法

3. **候选人分析**
   - 研究自知之明与面试表现的关系
   - 分析不同性格类型的表达模式

## 注意事项

1. **真实性**: 知识盲区配置应基于常见的认知偏差模式，保持真实性
2. **平衡性**: 不要所有技能都设为盲区，应选择1-3个关键领域
3. **一致性**: 自知之明水平应与盲区配置相匹配
4. **可测试性**: 确保盲区能够通过深入追问被发现

## 技术实现

### 核心文件

- `core/personality_generator.py` - 自知之明维度生成
- `agents/candidate_agent.py` - 知识盲区处理逻辑
- `agents/prompts/candidate_prompts.py` - 误判行为提示词
- `config/candidate_templates/*.json` - 候选人配置模板

### 扩展性

可以进一步扩展的方向：
- 添加动态知识盲区（面试过程中变化）
- 引入"学习曲线"模拟（随时间改善认知）
- 支持多维度的自我认知偏差
- 添加文化背景对自知之明的影响
