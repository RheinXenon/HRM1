# 测试脚本说明

本文件夹包含自动面试系统的各类测试脚本，用于验证系统功能的正确性和有效性。

## 测试脚本清单

| 脚本文件 | 用途说明 |
|---------|---------|
| `test_comprehensive.py` | 对比不同类型候选人的面试效果，验证追问机制能否有效区分真实水平 |
| `test_followup.py` | 测试追问机制是否能有效识别过度自信候选人的不懂装懂行为 |
| `test_iflow_api.py` | 测试与iflow API的连接是否正常 |
| `test_knowledge_misjudgment.py` | 测试知识误判功能，验证系统对过度自信和过度谦虚的识别能力 |
| `test_llm_scoring.py` | 真实调用LLM评估4种候选人类型的回答，验证LLM评分能力和一致性 |
| `test_llm_scoring_quick.py` | 快速版LLM评分测试，仅测试1个场景用于验证系统是否正常工作 |
| `test_overconfident_improved.py` | 测试改进后的面试官追问过度自信候选人的能力 |
| `test_personality_generator.py` | 测试性格生成器在不同策略和原型下的生成效果 |
| `test_random_demo_mode.py` | 生成随机候选人和公司配置，评估面试官的评估准确度（Demo模式） |
| `test_random_full_mode.py` | 生成随机候选人和公司配置，评估面试官的评估准确度（Full模式） |
| `test_score_normalization.py` | 测试评分标准化算法的正确性，使用预设维度评分验证标准化转换 |

## 使用方法

所有测试脚本都可以从项目根目录直接运行：

```powershell
# 运行单个测试
python test\test_comprehensive.py

# 随机测试支持参数
python test\test_random_demo_mode.py --num 10 --seed 42
python test\test_random_full_mode.py --num 10 --seed 42
```

## 注意事项

- 所有测试脚本需要在项目根目录运行
- 测试前请确保已安装所有依赖：`pip install -r requirements.txt`
- 测试需要配置有效的API密钥（.env文件）
